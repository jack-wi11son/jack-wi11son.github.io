## Overview

Built a fully autonomous mobile robot for dynamic arena tasks, securing **3rd Place Overall** in the RoboCup competition.

## System Architecture

- **Processing:** Powered by a Teensy 4.0 (600 MHz ARM Cortex-M7) for low-latency decision-making.
- **Algorithms:** Developed real-time spatial navigation, obstacle detection, dynamic path recalculation, and task prioritization algorithms.
- **Mechanical System:** Designed custom physical collection mechanisms and refined control feedback loops through extensive arena testing.
